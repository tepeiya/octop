# 道歉话术库

> 知识库 RAG 源文件。舆情监控专家在自动回复时，从此文件匹配话术。
> 匹配规则：用户评论关键词 → 本文件最相关段落 → 填入变量 → 生成回复草稿。

## 产品质量问题

### 通用模板
尊敬的用户您好，非常抱歉给您带来了不好的体验。我们非常重视您反馈的{product_issue}问题，已将您的反馈记录并转交产品团队。如需进一步处理，请私信联系我们，我们将第一时间为您解决。

### 食品/保健品
您好，非常抱歉听到这样的反馈。食品安全是我们的底线，我们已经将您反映的{specific_issue}情况上报给质量管理团队。请私信我们您的订单号，我们会立即安排售后处理，给您满意的结果。

### 电子产品
抱歉给您带来困扰！关于您提到的{device_issue}，这并非我们产品的预期表现。请您尝试{quick_fix}；如果问题仍然存在，请私信我们，我们将安排技术人员为您一对一排查。

## 物流配送问题

### 延迟
您好，非常抱歉物流延迟给您带来不便。订单{order_status}的原因是{delay_reason}。我们已联系物流公司加急处理，预计{estimated_time}送达。如需退换，请私信订单号。

### 破损
非常抱歉您收到商品时发现有破损！这不应该是您的体验。请拍照发送至我们的售后通道，我们将在{response_time}内为您安排补发或退款，无需退回破损商品。

### 丢件
非常抱歉给您带来这样的困扰。经查询，您的包裹{tracking_status}。我们将立即向物流发起索赔，并优先为您重新发出，预计{resend_time}送达。感谢您的耐心。

## 客服态度问题

### 通用
您好，首先为之前沟通中给您带来的不愉快真诚道歉。我们的客服应当始终保持专业和耐心，您反馈的情况已记录并反馈给客服主管，我们会加强培训。为了弥补您的不佳体验，我们为您准备了{compensation}，请私信领取。

## 售后退款问题

### 退款慢
您好，非常理解您的焦急。退款已于{refund_date}提交至{payment_channel}，通常需要{processing_days}个工作日到账。如果超出时效仍未收到，请私信我们，我们将加急跟进。

### 退款被拒
非常抱歉之前的处理结果让您不满意。我们重新审核了您的情况，现已为您{new_solution}。请查收，如还有疑问随时私信我们。

## 变量说明

| 变量 | 来源 | 示例 |
|------|------|------|
| {product_issue} | 从评论提取关键词 | "瓶身有划痕" |
| {order_status} | 查询物流 API | "在途" |
| {delay_reason} | 物流 API 返回 | "恶劣天气" |
| {estimated_time} | 物流 API 返回 | "9月16日" |
| {compensation} | 客服策略配置 | "50 元优惠券" |
| {response_time} | SLA 配置 | "2 小时内" |
| {refund_date} | 退款系统 | "9月14日" |
| {payment_channel} | 支付系统 | "支付宝" |
| {processing_days} | 渠道规则 | "3-5" |
| {new_solution} | 人工审核结果 | "重新退款" |
